# DESIGN.md — 安全开发环境方案

## 0. 设计依据

未命中学术 / 咨询 / 红金三个预设分支（本稿是技术方案沟通，不是论文、不是咨询报告、不是政务汇报），走通用设计原则。视觉来源：客户已看过的本地演示界面（SENTINEL 控制台）——白底、墨绿主色、等宽字体承载状态与文件名。目的：PPT 与现场演示是同一套语言，客户不会觉得是两份东西。

风格关键词：克制、可审计、工程感、不炫技、低饱和。

## 1. 画布与母版

- 画布：1280 × 720 px（16:9）
- Slide padding：上 26px、下 18px、左右 64px
- A · 标题块：y 0–118（标题基线 y=44，36px bold；副标 y=88，17px）
- B · 内容区：y 118–660（可用 542px）
- C · 页脚条：y 660–702；左侧 `SENTINEL · 安全开发环境方案`，右侧 `NN / 15`，均 14px，色 #6B7A72
- 封面 / 章节扉页 / 结束页省略 C 区页码，改用右下角 14px 章节标记

## 2. 颜色（4 个 hex + 半透明）

| 角色 | hex | 用途 | 面积 |
|---|---|---|---|
| 背景 | `#FFFFFF` | 全篇底 | 主色域 |
| 主色 | `#167762` | 标题、色块、流程节点、表头 | ≤ 40% |
| 墨色 | `#0F1E19` | 正文、强调数字 | 中性 |
| 强调 | `#C2410C` | 只用于"风险/未验证/需拍板"标记 | ≤ 8% |

半透明策略：
- 浅底块 `rgba(22,119,98,0.07)`，用于卡片底与表头下第二层
- 分隔线 `rgba(15,30,25,0.12)`
- 风险浅底 `rgba(194,65,12,0.08)`

渐变：仅封面与章节扉页允许 `linear-gradient(135deg, #167762 0%, #0F1E19 100%)` 单处使用，其余页面一律纯色。禁止全篇铺渐变。

## 3. 字体

| 层级 | 字体 | 字号 | 字重 | 行高 | 字距 |
|---|---|---|---|---|---|
| 封面主标 | Microsoft YaHei | 72 | bold | 1.15 | -0.5 |
| 章节大字 | Microsoft YaHei | 64 | bold | 1.1 | 0 |
| 巨型数字 | Consolas | 96 | bold | 1.0 | -2 |
| 页面标题 | Microsoft YaHei | 36 | bold | 1.3 | 0 |
| 卡片小标题 | Microsoft YaHei | 22 | bold | 1.4 | 0 |
| 正文 | Microsoft YaHei | 19 | normal | 1.65 | 0 |
| 表内文字 | Microsoft YaHei | 16 | normal | 1.45 | 0 |
| 注释 / 眉标 | Microsoft YaHei | 15 | normal | 1.5 | 0.5 |
| 页脚 | Microsoft YaHei | 14 | normal | 1.4 | 0 |

两套家族：正文/标题用 Microsoft YaHei，数字与文件名用 Consolas。禁止出现第三套。

## 4. 密度与留白

- 常规内容页：正文合计 ≥ 180 字，留白 ≤ 35%
- 卡片高度 ≥ 380px 时正文 ≥ 100 字；≥ 480px 时 ≥ 130 字
- 容器填充率 ≥ 85%，卡片尾部元素用 `marginTop: 'auto'` 钉底
- Hero 页（P01/P09/P15）留白可到 40%，但必须围绕焦点元素

## 5. 配图系统

本稿不使用摄影类图片（安全方案谈边界与流程，照片会削弱可信度）。

- L1 主视觉：结构图 / 流程图 / 大面积色块，占 B 区 ≥ 40%
- L2 支撑图：对比表、小结构图，≥ 280×180
- L3 角标：页脚左侧项目名与左侧章号色块，位置全篇一致

结构图一律用 Box + Text 拼装（flex 布局），不使用位图，保证在 PowerPoint 里可编辑、不糊。
