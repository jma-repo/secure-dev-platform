# 平台架构与验证边界

## 统一开发环境由什么组成

一个 monorepo 同时存放应用、共享安全模块、开发容器定义、CI 流水线、基础设施契约和文档。任何人克隆后都进入同一套工具版本，避免“在我电脑上是好的”。

## 安全门禁分三层

1. 提交前：Gitleaks 扫描暂存区，阻止凭据进入提交。
2. 合并前：GitHub Actions 运行测试、完整历史密钥扫描、Terraform 校验、依赖与镜像漏洞扫描、CodeQL 代码分析。必需检查通过且评审完成才允许合并。
3. 运行前：容器以非 root、只读文件系统、移除 capabilities、限制 CPU 与内存的方式启动，仅绑定回环地址。

## 已验证与未验证

本原型已经实际验证：Node 22.22.2 运行时、14 项测试、合成密钥被真实拦截、修复后放行、暂存区防绕过、源码扫描、Terraform 格式检查、Compose 配置解析。

尚未验证或需要客户环境补做的：容器构建与镜像漏洞扫描、Terraform 初始化与完整校验、GitHub Actions 与 CodeQL 实际运行、分支保护启用。工具安装成功不等于检查通过，配置写好了也不等于已经在客户环境生效。

## 不包含什么

本原型不包含 Kubernetes 集群、云资源、账号体系、单点登录、审计平台和生产级高可用。这些属于后续阶段，需要根据客户的网络边界、代码平台和许可证要求单独设计。
