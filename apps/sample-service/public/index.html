REPRODUCE LOCALLY

Your next three commands.

Run these from the repository root. Copying does not execute anything.

01

Start the workspace

Starts the local server on 127.0.0.1:4173 by default.

node apps/sample-service/server.mjs
02

Run the tests

Runs the Node.js test suite; trust the real exit code and output.

node --test
03

Prepare security tools

Prepares tools through the repository script. This step may download external binaries.

python scripts/bootstrap-tools.py gitleaks terraform trivy
If Gitleaks is unavailable, prepare the tools first, then refresh status and run the demo.

THE DELIVERY CONTRACT

Less infrastructure. More clarity.

A local customer-facing proof that keeps only the smallest scope that can run, be checked and be reproduced.

0cloud resources
0runtime third-party dependencies
Localloopback address by default

Zero runtime third-party dependencies refers to the local service and front-end libraries. Gitleaks, Trivy and Terraform are separate tools. This interface provides no cloud deployment, no sign-in, no Kubernetes and no cloud AI. The Local AI tab needs LM Studio serving a model on port 1234 on this machine.
