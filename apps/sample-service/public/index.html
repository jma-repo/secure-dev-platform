EXPLICIT LIMITS

CI CodeQL

待远端配置

需在远端仓库启用并执行 CI；本地演示不能证明远端检查成功。

Branch protection

待远端配置

需单独配置分支规则与必需检查；未读取或验证远端保护策略。

Container execution

已实跑

只读根文件系统、非 root、cap-drop ALL、资源受限，健康检查通过。镜像漏洞扫描仍受本机工具环境阻断。

REPRODUCE LOCALLY

Your next three commands.

在仓库根目录执行。复制不会自动运行命令。

01

Start the workspace

启动本地服务器，默认监听 127.0.0.1:4173。

node apps/sample-service/server.mjs
02

Run the tests

执行 Node.js 测试；以命令实际退出码和输出为准。

node --test
03

Prepare security tools

通过仓库脚本准备工具；此步骤可能下载外部二进制文件。

python scripts/bootstrap-tools.py gitleaks terraform trivy
若 Gitleaks 不可用，先准备工具，再刷新状态并运行演示。
